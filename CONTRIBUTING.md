# DA Slop: Instructions for Contributors

Contributions through GitHub pull requests are very welcome.

For a hypothetical AI-generated result related to "Foo bar" problem, please follow these steps:

1. Create a new directory `foo-bar`.
2. Create a human-written concise `foo-bar/README.md`, with a structure similar to what you see in other directories.
3. Put the AI slop preferably in `foo-bar/writeup.pdf` + `foo-bar/writeup.tex`, or `foo-bar/writeup.md`. Make sure you instruct the chatbot to create a writeup that is self-contained, complete, mathematically rigorous, and it cites all relevant prior work. Use additional files only if absolutely needed for independent verification of the result.
4. If you have any human-written notes related to the result (they can be very informal), put them in `foo-bar/human-notes.md`.
5. Add a line in `INDEX.md` as appropriate.
6. Add your name as a contributor in `README.md` if not yet there.

For mathematics in Markdown files, please follow [GitHub instructions for writing mathematical expressions](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions).
